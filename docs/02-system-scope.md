## Out of Scope by Default

The following are not assumed unless requirements explicitly justify them:

- microservices
- separate databases per module
- full general-ledger accounting
- banking engine
- complete payroll engine
- replacing Microsoft SharePoint
- replacing Microsoft Project
- custom email server
- custom identity provider
